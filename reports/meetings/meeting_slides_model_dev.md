### 기존 방법(DIFFUSE 베이스라인) vs PRISM의 핵심 차별점

| 한계 | DIFFUSE (Yao et al., Nat Methods 2022) | PRISM (본 연구) |
|------|----------------------------------------|-----------------|
| **유전자-수준 편향** | 동일 유전자 아이소폼이 유사한 기능 점수를 가짐 | ESM-2 δ_layer로 아이소폼-고유 변화만 포착 |
| **데이터 희소성** | 다수결 GO 라벨 → 레어 기능 학습 불가 | Focal Loss (γ=2) → 희귀 positive 집중 학습 |
| **전이 학습** | 근육 훈련 → 뇌에서 급격한 성능 저하 | 사전학습 ESM-2 신호 → 제로샷 전이 가능 |
| **검증 불가** | 블랙박스 점수 | BISECT 15-모듈 독립 수렴으로 해석 가능 |

### 핵심 설계 원리: δ_layer (Layer-Differential Embedding)

ESM-2 아이소폼 임베딩에서 두 층의 차이를 입력으로 사용:
```
δ = MaxAbsScaler( ESM-2_L30 − ESM-2_L15 )
         (640-dim)    (고수준 의미 표현)  (중수준 구조 표현)
```

- **L30 (상층)**: 도메인·기능 수준의 단백질 표현
- **L15 (중층)**: 2차 구조·국소 맥락 표현  
- **Δ = L30−L15**: "기능 층에서 구조 층을 뺀" 고수준 의미만 추출  
- **왜 절대값이 아닌 차이값인가?** 동일 유전자의 아이소폼은 절대 임베딩이 유사 → 유전자-수준 편향 발생. 차이값은 아이소폼 간 기능적 분기점만 포착.

```
입력 (640-dim δ_layer)
         │
    MLP: Dense(256, ReLU) → BN → Dropout(0.3)
         │
    Dense(128, ReLU) → Dropout(0.2)
         │
    Dense(64, ReLU)
         │
    Dense(82, sigmoid)  ← 82개 MF GO term 동시 예측
```

### Ablation Study 결과 — 무엇이 성능을 만드는가

| 변형 | All MF AUPRC | L2 Struct | 해석 |
|------|-------------|-----------|------|
| PRISM 베이스라인 (v15d) | 0.596 | 0.350 | 기준점 (절대 임베딩) |
| + T_ψ triplet + 64-dim | 0.717 | 0.622 | Triplet loss 추가 |
| + T_ψ triplet + 256-dim | 0.722 | 0.625 | Bottleneck 완화 |
| + T_ψ triplet + 640-dim | 0.709 | 0.607 | 고차원 bottleneck 역효과 |
| **v17f* (Triplet 제거)** | **0.734** | **0.637** | **최종 확정** |

**핵심 발견**:
- **Triplet loss 효과: −0.025** (오히려 해로움 — Dense+L2norm이 MaxAbsScaler보다 정보 손실)
- **Bottleneck 효과: +0.005** (부차적)
- **결론**: Raw δ_layer + MaxAbsScaler만으로 최적 성능

### PLM 일반화 실험 — ESM-2가 특별한가?

| PLM | 절대 임베딩 | **δ_layer** | Δ_gain |
|----|------------|------------|--------|
| ESM-2 150M | 0.6082 | 0.6693 | **+0.061** |
| ESM-2 650M | 0.6793 | 0.7339 | **+0.055** |
| ProtT5-XL | 0.6922 | 0.7288 | **+0.037** |

→ 3가지 PLM 전부에서 δ_layer 접근이 절대값보다 우수 (mean +0.051)  
→ δ_layer 원리가 특정 모델에 의존하지 않음을 실증

### Within-Gene 아이소폼 구별 능력 (pos_bias)

**pos_bias 정의**: 같은 유전자 내 아이소폼 간 PRISM 점수가 얼마나 의미있게 다른가?
```
pos_bias = V_within_gene / V_shuffle_null
→ > 1이면 유전자 내에서 기능적으로 의미있는 순위 부여
```

| GO 도메인 | 총 term | 유의 (BH<0.05) | 평균 pos_bias |
|-----------|---------|---------------|--------------|
| MF (분자 기능) | 82 | **81/81** | 0.665 |
| BP (생물학 과정) | 103 | **103/103** | 0.713 |
| CC (세포 구성요소) | 93 | **93/93** | 0.517 |

→ **278개 GO term 전체**에서 아이소폼-수준 구별 능력 입증 (기존 v15d muscle 11/13 대비 대폭 강화)

### 지표 정의 (처음 보는 분을 위해)

**Macro AUPRC (All MF)**
- AUPRC = Area Under Precision-Recall Curve
- Precision: 모델이 "이 기능을 가진다"고 예측한 것 중 실제로 맞은 비율
- Recall: 실제로 기능을 가진 아이소폼 중 모델이 발견한 비율
- **Macro**: 82개 GO term 각각의 AUPRC를 계산한 뒤 평균
- **왜 AUROC가 아닌 AUPRC?** GO 라벨이 극히 희소(positive < 5%)할 때 AUROC는 낙관적 — AUPRC가 실제 유용성을 정확히 반영

**L2_Struct AUPRC**
- "레어하지만 구조적으로 중요한 GO term"만 평가
- gene-mean baseline이 수학적으로 0.500이 보장되는 조건의 term들
- 이 조건에서 점수가 높을수록 유전자-수준 암기 없이 아이소폼-고유 신호를 학습했다는 의미

**Bootstrap CI (95%)**
- n=500~1000번 재샘플링으로 신뢰구간 추정
- 수치 주장의 통계적 유의성 담보

### 비교 포인트 해석

**왜 파인튜닝(D0/D1)이 PRISM보다 낮은가?**
- D0/D1 = 0.660 vs PRISM = 0.734: **+0.074 차이 (11%↑)**
- ESM-2를 brain 데이터로 파인튜닝해도 오히려 사전학습 신호 손실
- δ_layer가 파인튜닝 없이도 아이소폼-수준 신호를 더 잘 포착함

**Gene-mean이 k-NN(0.636)보다 낮은(0.465) 이유?**
- k-NN은 유사 서열을 가진 다른 아이소폼의 GO 전파 → 도메인 상동성 활용
- Gene-mean은 같은 유전자의 단순 평균 → 아이소폼 구별 없음

**L2_Struct에서 차이가 더 극적인 이유?**
- Gene-mean은 이 조건에서 0.500 (수학적 필연)
- PRISM L2 = 0.637: **gene-level 암기 없이** 아이소폼 자체 기능 예측 성공

PRISM이 올바른 순서로 점수를 매기는 비율

| 방법 | Domain-Ranking AUC | 해석 |
|------|-------------------|------|
| Gene-mean | 0.500 | Random (이론적 필연) |

→ PRISM은 ESM-2의 내재 도메인 신호를 보존하면서 GO 예측으로 정제함

### 실험 설계
- UniProt에 "기능적으로 다름"이 수동 큐레이션된 아이소폼 쌍 45개 수집
- 각 쌍: "기능 보유 이소폼 A" vs "기능 소실 이소폼 B"
- 질문: **PRISM이 A > B를 올바르게 예측하는가?**
- 42쌍 평가 가능 (3쌍 UniProt 데이터 없음)

### 결과

| 조건 | 정확도 | p-value | 해석 |
|------|--------|---------|------|
| 전체 42쌍 | 26/42 = **61.9%** | p=0.082 | 유의 경향 |
| **Gap ≥ 0.10 (9쌍)** | **9/9 = 100%** | **p=0.002** | 구조적으로 뚜렷한 쌍에서 완벽 예측 |
| Gap < 0.05 (30쌍) | 16/30 = 53.3% | ≈ random | 미세한 차이는 예측 한계 |

**Length bias 통제 분석**:
- ρ(길이 차이, 예측 방향 정확도) = +0.019, p=0.911 → **길이 편향 경험적으로 기각**
- Partial r(gap, correct | len_diff) = +0.274 → gap이 길이보다 34× 큰 예측력

## 연구의 핵심 Novelty 요약

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  이 연구가 새로운 이유 (3가지)                                               │
└─────────────────────────────────────────────────────────────────────────────┘

① 방법론적 기여:
   δ_layer (Layer-Differential ESM-2) = 아이소폼-고유 기능 신호 포착
```
